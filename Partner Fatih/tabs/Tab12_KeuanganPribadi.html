Pengaturan Google Gemini AI Key

Untuk menggunakan scan struk dan analisis suara tanpa batas, masukkan API Key Google Gemini (Gratis dari Google AI Studio). Kunci tersimpan 100% aman di browser Anda dan tidak pernah dikirim ke server luar selain Google API.

Cara mendapatkan API Key Gratis:

1. Kunjungi Google AI Studio.

2. Login dengan akun Google Anda.

3. Klik "Create API Key" dan salin kunci ke kolom di atas.
